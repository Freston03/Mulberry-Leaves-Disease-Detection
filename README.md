# Mulberry-Leaves-Disease-Detection
This project implements a deep learning-based system for detecting diseases in mulberry leaves using Convolutional Neural Networks (CNNs). Accurate identification of leaf diseases is crucial for sericulture and agriculture, as it helps farmers take timely preventive measures, improving crop yield and quality.

The system is trained on a dataset of mulberry leaf images labeled with various disease types. It includes preprocessing steps such as resizing, normalization, and augmentation to improve model robustness. The CNN model is designed to extract key features from leaf images and classify them into different disease categories with high accuracy.

Key features include:

Dataset preprocessing and augmentation for better generalization

CNN-based model for effective disease classification

Performance evaluation with metrics like accuracy and confusion matrix

Supports deployment for real-time prediction in agricultural applications

This repository contains the full code for training, testing, and evaluating the model, along with the trained model file (linked via Git LFS or external storage). It is suitable for researchers, agritech developers, and farmers looking for automated solutions to monitor mulberry leaf health.
